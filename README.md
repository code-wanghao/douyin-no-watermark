# 抖音 · 无水印保存（电脑版）

[![Download](https://img.shields.io/badge/Download-Releases-brightgreen?style=flat-square)](https://github.com/code-wanghao/douyin-no-watermark/releases/latest)
[![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-blue?style=flat-square)](#环境要求)
[![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)](LICENSE)

在抖音电脑版里：

- **评论区的图片** —— 点开看到的就是原图，点保存存下来的也是原图
- **视频 / 图文作品** —— 点"下载"存下来的就是无水印版本
- **作者关了下载（按钮是灰的）** —— 可以把按钮变回可点
- **点赞 / 收藏即标记** —— 结束时把标记过的作品一键下载，完全不依赖客户端按钮

不用改 App、不用手动导出、不用装任何去水印软件，也不需要会写代码。四个功能可以**任意组合启用**。

> 它的做法不是"去水印"，而是**不让客户端拿到带水印的那一份**。

## 它解决什么问题

抖音评论区里别人发的图片，你在电脑版里存下来总是带一层水印。

这层水印不是"印"在图上的，而是**客户端主动换了一张图** —— 详见下一节。
本工具就是拦住这个替换动作。

适合的场景：收藏评论区的图、给朋友发原图、留素材。

---

## 原理

评论接口返回的每条图片对象里，其实同时给了好几份地址：

| 字段 | 内容 |
| --- | --- |
| `origin_url` | **原始图**，全分辨率、无水印 |
| `medium_url` | 中图（列表里显示的小图） |
| `thumbnail_url` | 缩略图 |
| `owner_watermark_image` | 服务器**预渲染好的带水印图**，客户端保存时用的就是它 |
| `download_url` | 保存路径用的地址，同样指向带水印那份 |

所以"保存带水印"不是客户端画上去的，是它**从服务器换了一张图下载**。

抖音电脑版本质上是个 Electron 外壳（Chromium 内核），调用的是和网页版
**完全相同的那套 Web API**（`/aweme/v1/web/comment/list/`）。所以做法是：

在本地起一个代理，只拦截 `*.douyin.com` 的 HTTPS，把接口返回里
**指向带水印的那两个字段换成原图地址**。客户端无论用哪个字段去显示或保存，
拿到的都是原图。

实测数据（同一张评论图）：

| 请求 | 模板 | 字节数 |
| --- | --- | --- |
| 列表渲染时加载 | `~tplv-…-medium-webp:248:332:q75.webp` | 7,976 |
| 点开查看时加载 | `~tplv-…-origin-webp:q75.webp` | 51,680 |

接口本来就是"干净的变体"和"水印版本"分开存的，我们只是把水印那份的指针改掉。

## 快速开始

### 1. 下载

到 [Releases](https://github.com/code-wanghao/douyin-no-watermark/releases/latest) 下载
`douyin-no-watermark-proxy.zip`，解压到任意目录（路径别带奇怪的符号就行）。

> 包里已经带了 Node.js 运行时，**不需要装任何东西**。

### 2. 启动

双击 `启动.bat`。

第一次运行会先问你**要启用哪些功能**：

```
请选择要启用的功能（可多选，用逗号分隔，例如 1,2）：

  1. 评论区图片去水印　—— 点开评论图片看到的就是原图，可以只保存你点开过的那几张
  2. 作品去水印　　　　—— 保存视频 / 图文作品时，拿到的是无水印版本

输入编号，直接回车＝两个都启用：
```

选完会记住（存在 `features.json`）。以后想改，双击 `选择功能.bat` 重选即可。

接着会问你：

```
现在安装根证书吗？会弹出一次 Windows 安全警告，选"是"。(Y/n，直接回车＝安装)
```

按回车或输入 `y`。接着 Windows 会弹一个安全警告框，**点"是"**。

> **这一步必须同意。** 不同意的话工具会静默失效——抖音看不懂我们签发的证书，
> 代理起不到任何作用，而且不会有任何报错提示你。

### 3. 用

看到这几行就说明起来了：

```
抖音去水印代理

  功能    评论区图片 · 作品去水印 · 解除限制 · 点赞收藏
  存档    C:\Users\86147\Pictures\抖音原图

  去抖音里重新加载一次内容；然后 点开评论图 / 点作品的下载 / 点赞或收藏 都可以。
  结束后按【回车】收尾（别按 Ctrl+C，那是关窗口）。
```

上面就是全部界面 —— 技术细节都写在 `logs\` 里，不往屏幕上刷。

然后：

1. 切回**抖音电脑版**，换一个视频（或者划走再点回来），**让评论区重新加载**。
2. 点开评论里的图片 —— 此时看到的就是原图了。
3. 往下滑，**点开你喜欢的那些图**（这一步有意义，见下一节）。
4. 回到控制台窗口，**按回车**结束。

> ⚠️ **不要按 Ctrl+C。** 在 `.bat` 里按 Ctrl+C 会先弹出 cmd 自己的
> `终止批处理操作吗(Y/N)?`，那时候选 Y 会把整个窗口关掉，脚本来不及还原系统代理。
> 已经误触也没事，双击 `恢复系统代理.bat` 兜底即可。

## 功能开关

四个功能互相独立，**可以任意组合**：

| 编号 | 功能 | 配置里的 key | 效果 |
| --- | --- | --- | --- |
| 1 | 评论区图片去水印 | `comment` | 点开评论图片看到的就是原图，点保存存下来的也是原图 |
| 2 | 作品去水印 | `aweme` | 视频 / 图文作品点"下载"存下来的就是无水印版本 |
| 3 | 解除下载限制 | `unlock` | 作者关了下载、按钮变灰时，把按钮变回可点 |
| 4 | 点赞/收藏即标记 | `pick` | 你点赞或收藏过的作品会被记下，结束时一键下载 |

2 和 3 的区别：**2 管"文件没水印"，3 管"按钮点得动"**。作者没关下载时，3 不起作用。
4 是唯一**完全不依赖客户端 UI** 的路径 —— 按钮灰不灰都能拿到文件。

四种控制方式，从简单到灵活：

| 方式 | 怎么做 |
| --- | --- |
| 首次运行时选 | 启动时会问你，输入编号（如 `1,2`；直接回车＝全部启用） |
| 随时重选 | 双击 `选择功能.bat` |
| 临时指定 | `启动.bat --features comment,aweme` 这类组合，或用 `all` / `none` |
| 手改配置 | 编辑 `features.json`，`features` 数组里留哪个就是开哪个 |

优先级：命令行 `--features` ＞ `features.json` ＞ 首次交互选择 ＞ 默认两个都开。

启动时控制台会明确打印当前启用了什么，下面那句操作提示也会跟着已启用的功能变。

### 作品去水印是怎么实现的

客户端自己的下载逻辑决定了它去哪里取文件（这段是从它的前端包里挖出来的）：

```js
misc_download_addrs.suffix_scene.url_list.length > 0
  ? 用它                                  // ① 优先
  : has_download_suffix_logo_addr && 有地址
    ? download_suffix_logo_addr.url_list   // ② 带 logo 后缀的
    : download_addr.url_list;              // ③ 兜底
```

这三个都是"下载专用"的带水印 / 带 logo 地址；而 `play_addr` 是边播边下用的流，是干净的。
所以做法就是把这三个下载字段都指向播放地址。取源时优先用 `bit_rate` 里码率最高的那一档，画质更好。

图文同理：`images[].url_list` 是干净的，`download_url` 是带水印那份。

### 解除下载限制是怎么实现的

客户端判断"能不能下载"只看一个布尔值。这段是从它的前端包里挖出来的原文：

```js
if (!_.detail?.video_control.allow_download)
  return Toast.info("无法下载");
```

菜单项要不要显示，用的也是同一个字段。所以把 `video_control.allow_download` 改开
（连同 `download_info.level`、`prevent_download`），灰掉的按钮就变回可点了。

> 视频文件必须能播才可能被看到，所以不存在"服务端真的不给文件"这件事。
> 但要注意：作者设"不允许下载"是他的明确意愿，绕过它建议只用于个人留存。

### 点赞/收藏标记是怎么实现的

代理本来就看得见你发出的请求，其中两个动作接口很关键：

| 动作 | 接口 |
| --- | --- |
| 点赞 | `/aweme/v1/web/commit/item/digg/` |
| 收藏 | `/aweme/v1/web/aweme/collect/` |

滚动时，代理从作品接口的响应里记下 `aweme_id → 干净地址 + 文案 + 作者`（**只记地址，几百字节**）；
你点赞或收藏时，把对应作品标记成"要的"。结束时只列被标记的，问你要不要下载。

## 使用

启动后会一直挂着，控制台每 20 秒报一次状态：

```
  · 运行中 · 评论图 3 · 作品 2
```

只有你**明确标记**过的内容才会被记下来：

| 你做的动作 | 控制台提示 | 被记下的内容 |
| --- | --- | --- |
| 点开一张评论图 | `· 点开  某某用户 · 这条评论的内容` | 那张原图 |
| 点赞 / 收藏一个作品 | `· 标记  点赞：作者 · 文案` | 那个作品 |

**刷过去但没点开、没点赞的，一律不统计。** 它们仍然会被改写成无水印（否则你点开时看到的还是水印版），
但不进清单、不计数、也不会被下载。

## 只下载你标记过的那几个

按回车结束时会列出清单，问一句就下载：

```
评论图  你点开过 2 张：
  1. 某某用户 · 评论内容
  2. ……
作品  你点赞/收藏过 1 个：
  1. 某某作者 · 文案…   (视频)

下载上面这些？  y=下载   回车=不下载：
```

| 输入 | 结果 |
| --- | --- |
| `y` | 下载清单里的全部 |
| 直接回车 | 不下载（改写照常生效，你在客户端里存图/下载本来就是干净的） |

视频和图文自动分开放：`视频\作者_文案.mp4`、`图文\作者_文案\01.jpg`。
视频文件大，下载时会每 25% 报一次进度。

先核对清单条数和你实际点开的对不对，再决定下载。不对的话说明这个客户端版本
"点开"的请求特征变了，用 `追踪模式.bat` 跑一遍把日志发出来即可定位。

## 图片存到哪

默认保存到 Windows 的"图片"文件夹下的 `抖音原图`：

```
C:\Users\<你的用户名>\Pictures\抖音原图\
```

跑完会自动打开这个文件夹。文件命名是 `01_作者名.webp` 这种，
另外有一份 `原图链接.txt` 存着全部直链。

想换位置：

```bat
启动.bat -o D:\我的图
```

> 注意：**不能直接放到盘符根目录**（比如 `D:\抖音原图`）。
> Windows 默认不给普通程序在盘根建文件夹的权限，会报 `EPERM`。
> 工具会自动跳过不可写的目录并换一个能写的地方，日志里会说明。

## 抓到的到底是不是"原图"

分三层，别混在一起：

**一、尺寸和内容：是。** 接口模板名直接标着 `origin`（原始尺寸、未裁剪），
和列表用的 `medium`（248×332）差 6.5 倍字节数。而且平台自己就把"原图"和
"带水印图"当两个独立对象存，我们取的是前者。**无水印、全分辨率，这层是确定的。**

**二、格式和画质：不是上传者当初上传的那个文件。** 模板后缀是 `origin-webp:q75`——
尺寸是原始的，但 CDN 仍做了转码（webp 格式、75% 质量），因为客户端请求接口时带了
`pc_img_format=webp`。画质远好于平台预览图，但严格讲不等于上传原始文件。

**三、上传者自己加的水印或文字：会保留。** 那种在源文件里，任何方式都去不掉。

每次下载时控制台会打印实测分辨率并和接口声明的原始宽高对比，你可以自己核对：

```
  1/3    01_某某.webp  1080×1440  51 KB
```

## 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击 `启动.bat` 窗口一闪就没了 | 看 `logs\launcher.log` 和 `logs\proxy-*.log`，里面记了完整原因 |
| 抖音里图片还是带水印 | ① 评论区没重新加载（划走再点回来）；② 证书那步点了"否"；③ 窗口里显示 `改写 0 个字段` 说明接口字段变了，把日志发出来 |
| 浏览器打不开网页了 | 系统代理没还原。双击 `恢复系统代理.bat` |
| 抖音提示网络异常 | 证书没装上，双击 `安装根证书.bat` |
| 端口 8080 绑不上（EACCES） | 常见于装了 360 / 2345 等安全软件。工具会自动换端口，看到 `已自动改用 8899` 是正常的 |
| 一条 `· 点开` 都没出现 | 要么确实没点开图；要么是以前看过的图命中了旧缓存。换没看过的视频重试 |
| 提示 Node.js not found | 只会在你没用发行包、直接跑源码时出现。装 Node.js 或把 `node.exe` 放进 `proxy\node\` |
| 杀毒软件报警 | 这个工具会装根证书 + 接管系统代理，行为特征和抓包工具一样，属于误报。需要手动放行 |

每次运行的完整日志都在 `proxy\logs\` 下，双击 `查看日志.bat` 直接打开该目录。

## 另一条路：给浏览器用（油猴脚本）

`userscript/douyin-comment-origin.user.js` 是**不装代理**的方案，适合在
Chrome / Edge 里直接看网页版 `www.douyin.com` 的场景。

安装：

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. Tampermonkey 面板 → 新建脚本 → 把 `.user.js` 全文粘进去 → 保存
3. 打开 `www.douyin.com` 视频页，展开评论区往下滚
4. 右下角出现"评论原图 N"按钮，点开可单张或批量下载

也可以零安装使用：打开视频页按 F12，把脚本全文粘进 Console 回车。

两种方案的取舍：

| | 代理方案 | 油猴脚本 |
| --- | --- | --- |
| 适用端 | **电脑版客户端** | 浏览器网页版 |
| 需要装证书 | 是 | 否 |
| 能"只存点开的" | 是 | 否（提供列表让你挑） |
| 使用时的存在感 | 后台常驻 | 页面右下角一个按钮 |

## 自己打包分发

仓库里不含 Node 运行时（88 MB 的二进制不适合入库）。要做成"发出去就能用"的包：

**方式 A：直接下 Release**（推荐，已经内置运行时）

**方式 B：自己打**

1. 从 [nodejs.org](https://nodejs.org) 下载 Windows 版 Node.js 18+，把 `node.exe`
   放到 `proxy\node\` 目录（新建这个目录）
2. 双击 `proxy\打包分发.bat`
3. 生成 `proxy\douyin-no-watermark-proxy.zip`，这个包对方解压双击就能用

启动脚本查找运行时的顺序是：`proxy\node\node.exe` → 系统 PATH → 常见安装位置。

## 已知局限

这套方案依赖抖音自己的接口设计，所以稳定性取决于对方不改：

| 依赖 | 改了会怎样 | 怎么发现 |
| --- | --- | --- |
| 接口仍有 `origin_url` / `owner_watermark_image` | 改写失效，水印回来 | 窗口显示 `改写 0 个字段` |
| 保存时确实去下载带水印那份 | 看着干净、存下来带水印 | 存一张试试 |
| 列表取中图、点开取原图 | "点开识别"失效（改写仍正常） | 一条 `· 点开` 都不出现 |
| 下载限制只是客户端标志位 | 解除下载限制失效 | 按钮还是灰的 |
| 点赞/收藏走那两个接口 | 标记失效（去水印仍正常） | 一条 `· 标记` 都不出现 |

如果这些接口或字段变了，用 `追踪模式.bat` 跑一次，把 `logs\` 里的日志发出来就能定位——
诊断信息全都写在日志里，不占屏幕。

另外：

- **仅有 Windows 版。** 代理内核跨平台，但设置系统代理那一段是 Windows 专用的。
- 运行期间系统代理会指向本工具。非抖音流量走原始隧道转发、**不解密**，但确实会经过这个进程；退出时自动还原，另有独立看门狗进程兜底。
- **必须装一次本地根证书**。这是所有 HTTPS 抓包工具的固有代价（Fiddler、Charles、mitmproxy 都一样）。证书和私钥只在本机生成、不外传，卸载脚本可以干净移除。**如果你不理解这一步的含义，请不要使用本项目。**

## 目录结构

```
.
├── proxy/                        # 主方案：本地代理（电脑版）
│   ├── proxy.mjs                 #   代理本体 + 接口改写 + 采集/下载
│   ├── certgen.mjs               #   零依赖生成本地根证书与服务器证书（手写 DER 编码）
│   ├── imgsize.mjs               #   从文件头读真实分辨率，用于自证"是不是原图"
│   ├── 启动.bat                  #   正常使用入口
│   ├── 选择功能.bat              #   重选要启用哪些功能（写入 features.json）
│   ├── 追踪模式.bat              #   诊断入口：记录每一次图片请求
│   ├── 安装根证书.bat / 卸载根证书.bat
│   ├── 恢复系统代理.bat / 查看日志.bat
│   ├── 打包分发.bat              #   打出自带运行时的分发包
│   └── features.json             #   功能开关配置（首次运行时自动生成）
├── userscript/                   # 备选方案：浏览器网页版油猴脚本
│   └── douyin-comment-origin.user.js
└── docs/
    ├── proxy-使用说明.md         # 代理方案的详细说明与排查
    └── userscript-使用说明.md    # 油猴脚本的说明
```
