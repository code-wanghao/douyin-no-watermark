# 抖音电脑版 · 无水印保存

装好之后，你在电脑版里：

- **点开评论图片看到的就是原图，点保存存下来的也是原图**
- **视频 / 图文作品点"下载"，存下来的就是无水印版**（仅限作者允许下载的作品）

不需要额外导出、不需要改 App、也不用装任何去水印软件。

## 第一次用，只做三件事

1. 把整个文件夹解压到你自己能找到的位置。**别放 `C:\Program Files` 或盘符根目录**——那些地方普通程序写不了文件，证书生成会失败。
2. 双击 `启动.bat`。第一次会问你要启用哪些功能；接着 Windows 弹一次安全警告，**点"是"**（装的是在你本机生成的证书）。
3. 切回抖音电脑版，**划走再点回来**让内容重新加载一次，然后正常用。用完回到黑窗口按【回车】收尾。

> 包里已经带了 Node.js 运行时，**不需要装任何东西**。

## 原理

评论接口返回的每条图片对象里有一组地址字段：

| 字段 | 内容 |
| --- | --- |
| `origin_url` / `medium_url` / `thumbnail_url` | 原图、中图、缩略图，三档**都是干净的** |
| `owner_watermark_image` | 服务器预渲染好的**带水印**图，客户端保存时用的就是它 |
| `download_url` | 保存路径用的地址，也是带水印那份 |

所以水印不是"印"上去的，是客户端**主动换了一张图**。
本工具在 `127.0.0.1` 起一个代理，劫持 `*.douyin.com` 的 HTTPS，把接口 JSON 里
**带水印的那两个字段**（`owner_watermark_image` / `download_url`）整体替换成 `origin_url` 的副本，
连 `uri` 和尺寸一起换，保证客户端拿到的是自洽的原图。保存和显示都会落到原图上。

**三档干净变体故意不动**，因为客户端本来就是"列表渲染取小图、点开查看取大图"。
如果把它们也全换成同一个原图地址，客户端在列表渲染时就把原图下完了，你点开只是命中缓存——
于是"你点开了哪张"在网络层上就再也看不出来了。保持原样，这个动作才可识别。

解密范围是 `*.douyin.com` 加图片 CDN（`douyinpic.com` / `byteimg.com` 等，都在证书 SAN 里），
其余域名一律原始隧道转发，不解密、不干预。

## 使用

1. 双击 `启动.bat`。
2. **第一次运行会让你选启用哪些功能**（见下一节），选完会记住。
3. 接着会让你确认安装一个**本地根证书**（Windows 会弹一次安全警告，选"是"）。
   这是能解密抖音 HTTPS 的前提，任何抓包工具都要这一步。
4. 脚本把系统代理指向本机端口并开始工作。
5. 切回抖音电脑版，**切换一下视频让内容重新加载**（划走再点回来，或者重启一下客户端）。
   已经加载过的评论是内存里的旧数据，不会经过代理，必须重载一次。
6. 然后是正常使用，**只有你明确点开过的评论图片才会被记下来**：

   | 你做的动作 | 被记下来的内容 | 控制台提示 |
   | --- | --- | --- |
   | 点开一张评论图片 | 那张原图 | `· 点开  作者名 · 评论内容` |

   **刷过去但没点开的，一律不统计**（它们仍然会被改写成无水印，只是不进清单、不占地方）。

7. 用完回到控制台窗口，**直接按回车**（或输入 `q` 再回车），系统代理会自动还原。
8. 收尾时列出你点开过的评论图，问一句就下载：

   ```
   评论图  你点开过 2 张：
     1. 某某 · 这条评论
     2. ……

   下载上面这些？  y=下载   回车=不下载：
   ```

## 功能开关（可选装哪一部分）

工具里有两个互相独立的功能，可以任意组合：

| 编号 | 功能 | 效果 |
| --- | --- | --- |
| 1 | **评论区图片去水印** | 点开评论图片看到的就是原图，点保存存下来的也是原图 |
| 2 | **作品去水印** | 视频 / 图文点"下载"存下来的就是无水印版 |

> 功能 2 只对**作者允许下载**的作品生效。作者关闭下载的作品（按钮是灰的）不在本工具范围内。

**选择方式，从简单到灵活：**

1. **第一次运行时会问你**，输入编号即可（可多选，如 `1,2`；直接回车 = 全部启用）。选完记在 `features.json` 里，以后不再问。
2. **想改：双击 `选择功能.bat`**，重新选一次。
3. **只想临时指定：** `启动.bat --features comment` / `aweme`，用逗号组合；或者 `--features all` / `--features none`
4. **想手改配置：** 直接编辑 `features.json`，`features` 数组里留哪个就是开哪个。

启动时控制台会明确打印当前启用了什么，提示也会跟着已启用的功能变。

**作品去水印是怎么做的**：客户端自己的下载逻辑（从它的前端包里挖出来的）会优先取
`misc_download_addrs.suffix_scene`，其次 `download_suffix_logo_addr`，兜底 `download_addr` ——
这三个都是"下载专用"的带水印/带 logo 地址。而 `play_addr` 是边播边下用的流，是干净的。
所以把这三个下载字段指向播放地址即可；优先取 `bit_rate` 里码率最高的那一档，画质更好。
图文同理（`images[].url_list` 是干净的，`download_url` 是带水印那份）。

> **不要按 Ctrl+C。** 在 .bat 里按 Ctrl+C 会先弹出 cmd 自己的
> "终止批处理操作吗(Y/N)?"，那时候选 Y 会把整个窗口关掉，脚本来不及还原代理。
> 如果已经误触，双击 `恢复系统代理.bat` 兜底即可。

控制台只显示"点开 / 抓到"这类人话，技术细节都写进 `logs\` 里的日志。
日志里出现 `[接口] ... 改写 N 个字段` 就说明改写生效了。

## 原图存到哪

按回车收尾时脚本会问你要下载哪些，**输入 `y` 就是只下载你点开过的那些**：

- 保存目录：`C:\Users\<你的用户名>\Pictures\抖音原图\`（首次下载时才创建，跑完会自动帮你打开这个文件夹）
- 文件名：`序号_作者名.jpg` / `.webp`
- 同目录下还会有一个 `原图链接.txt`，是所有原图的直链

想换地方，用 `启动.bat -o D:\我的图`，或者在 `启动.bat` 上右键 → 编辑，把命令行参数加进去。

## 抓到的到底是不是"原图"

分三层说，别混在一起：

**一、尺寸和内容：是。** 接口的模板名直接标着 `origin`（原始尺寸、未裁剪），
同一张图还有 `medium`（248×332 的缩略图）。实测字节数 **51.7 KB vs 8 KB**，差 6.5 倍。
更重要的是：平台自己把"原图"和"带水印图"当成两个独立对象存（`origin_url` 与
`owner_watermark_image`），我们取的是前者。**无水印、全分辨率，这一层是确定的。**

**二、格式和画质：不是上传者当初的那个文件。** 模板后缀是 `origin-webp:q75` ——
尺寸是原始的，但 CDN 仍然做了转码（webp 格式、75% 质量）。
原因是客户端请求评论接口时带了 `pc_img_format=webp` 这个参数。

> **所以"抓到的比手机存的还小"是正常的**：手机保存的是 JPEG，而接口给的是 WebP 75% 质量。
> 同一张图、同样分辨率，WebP q75 比 JPEG 小三到四倍很常见。这不是分辨率被砍了。

**这一版会尽量往更清晰的方向取。** 下载时会为每张图构造几个候选地址：

| 候选 | 做法 |
| --- | --- |
| 原地址 | 接口给的 `origin_url` |
| 去模板 | 去掉 `~tplv-…` 那段，取 CDN 上的原始对象 |
| 提质量 | `q75` → `q100` |
| 去缩放 | 去掉 `:宽:高` 这类尺寸参数 |

先用 `HEAD` 只问大小（不拉正文，省流量），再把**最大的那一份**真正下下来。
日志里会留下对比记录，例如：

```
[画质] 01_某某.webp  候选 133KB / 取不到 / 486KB  选中 …~tplv-p14lwwcsbr-origin-webp:q100.webp
```

如果哪个候选 CDN 不给（签名不匹配会 403），它会自动退回原地址，**绝不会比原来更差**。

**三、上传者自己加的水印或文字：会保留。** 那种东西在源文件里，任何方式都去不掉。

### 怎么自己核对

每次下载时控制台会打印实测分辨率；**只有在和接口声明的原始宽高对不上时才额外警告**，
所以看到干净的尺寸行就说明 CDN 给的是原始分辨率：

```
  1/3    01_某某.webp  1080×1440  51 KB
```

如果某行出现 `⚠ 800×600（接口声明 1080×1440）`，说明那张拿到的不是原始尺寸，把它反馈出来。
解析逻辑用真实图片做过交叉验证（对比第三方 `image-size` 库和独立实现，零分歧）。

> 想做更进一步（拿到未经 webp 转码的原始文件）在理论上可行 —— 把 URL 模板里的
> `origin-webp:q75.webp` 换成未压缩格式。但不同图床的模板命名不统一，需要逐桶验证，
> 目前没有做。

## 三个必须知道的事

**一、会装一个根证书。**
证书和私钥只生成在你本机 `certs\` 目录里，不会外传。但它意味着"持有该私钥的人可以冒充 HTTPS 网站"——
这是所有 HTTPS 抓包工具的固有代价（Fiddler、Charles、mitmproxy 都一样）。
不想用了就双击 `卸载根证书.bat`，干净移除。

**二、运行期间系统代理会指向本工具。**
非抖音域名的流量走原始隧道转发，不会被解密，但确实会经过这个进程。
正常情况下退出时会自动还原；即使进程被强杀，还有一个独立的看门狗进程负责把设置还原。
万一还是没还原，双击 `恢复系统代理.bat` 手动兜底。

**三、必须让评论区重新加载一次。**
启动代理之前已经加载的评论不会经过代理。切换视频、或者重启客户端都能触发重新拉取。

## 排查

| 现象 | 处理 |
| --- | --- |
| 控制台一直显示"等待中…" | 评论区没重新加载。切换视频再回来，或重启客户端 |
| 保存下来的图还有水印 | 先确认窗口出现过 `改写 N 个字段`；若改写了仍带水印，把抖音彻底退出重开（旧图可能被客户端缓存过） |
| 提示"安装失败：证书没能写进受信任的根证书颁发机构" | 多半被安全软件拦了。右键 `安装根证书.bat` → 以管理员身份运行；或先退出安全软件再装 |
| 浏览器打不开网页 | 系统代理没还原，双击 `恢复系统代理.bat` |
| 抖音提示网络异常 | 证书没装上，双击 `安装根证书.bat` 后重试 |
| 端口 8080 绑不上（EACCES） | 脚本会自动换端口，看到 `已自动改用 8899` 是正常的；想固定就加 `--port 8899` |
| 一条 `· 点开` 都没出现 | 要么这次确实没点开图；要么点开的是以前看过的图，客户端命中了旧缓存。换没看过的视频再试 |
| 列表里的缩略图还是带水印 | 正常情况下缩略图本身就是干净的；如果确实带，说明这个接口给了水印缩略图，把日志发我 |
| 提示 Node.js not found | 编辑 `_node.cmd`，把 `NODEEXE` 指到你机器上的 `node.exe` |

每次运行都会在 `logs\` 下留一份完整日志（双击 `查看日志.bat` 打开该目录）。
窗口一闪而过时，日志里能看到它到底停在哪一步、报了什么错。

## 卸载

1. `卸载根证书.bat` —— 移除根证书
2. `恢复系统代理.bat` —— 还原代理设置

然后把 `douyin-no-watermark` 整个目录删掉即可，不留残余。

## 发给别人 / 换台电脑用

### 直接发这个包

双击 `打包分发.bat`，会生成 `douyin-no-watermark-proxy.zip`（约 34 MB）。把它发给对方，解压后双击 `启动.bat` 即可。

包里已经带了 `node\node.exe`，对方**不需要装 Node.js**。打包时会自动排除 `certs\`（每台机器自己生成的证书）、`logs\` 和下载的图片。

对方第一次运行时会照常弹一次"安装根证书"的确认——那一步是必须的，装的是**在他自己机器上生成**的证书，不是你的。

### 对方第一次用，也是三件事

1. **解压到自己能找到的地方**（桌面、文档都行）。别放 `C:\Program Files`，别直接放在盘符根目录。
2. **双击 `启动.bat`**，功能选择直接回车（两个都开），弹出的安全警告点**"是"**。
3. **在抖音里划走再点回来**让内容重新加载，之后点开评论图 / 点作品的下载就是无水印的了。

### 对方可能会遇到的三个卡点

| 卡点 | 原因 / 解法 |
| --- | --- |
| 双击 `.bat` 一闪而过 | 看 `logs\launcher.log` 和 `logs\proxy-*.log`，里面写了停在哪一步 |
| 解压后双击没反应，或提示"Windows 已保护你的电脑" | 压缩包是从网上传过来的，Windows 给它打了"来自网络"的标记。右键 zip → 属性 → 勾上**解除锁定** → 确定，再解压一次 |
| 杀毒软件报警 | 这个工具会装根证书 + 接管系统代理，行为特征和抓包工具一样，属于误报。需要手动放行，否则证书装不上、代理也起不来 |

### 对方需要知道的三件事

1. **会装一个本地根证书。** 不装就没法解密抖音的 HTTPS，代理起不来。这是所有抓包工具的固有代价。卸载用 `卸载根证书.bat`。
2. **运行期间系统代理会指向这个工具。** 非抖音流量走原始隧道转发、不解密，但确实会经过这个进程；退出时自动还原。
3. **只解密抖音相关域名**（`*.douyin.com` 与图片 CDN），其余一律不碰。

### 普适性边界（说实话的部分）

这套方案**不是靠某个技巧，而是靠抖音自己的数据**，所以它有多可靠，完全取决于抖音那边不变：

| 依赖的东西 | 变了会怎样 | 表现 |
| --- | --- | --- |
| 接口里仍有 `origin_url` / `owner_watermark_image` 字段 | 改写失效，水印回来 | 窗口里显示 `改写 0 个字段` |
| 客户端保存时确实去下载 `owner_watermark_image` | 保存下来的仍是带水印图 | 图片能看但存下来带水印 |
| 客户端"列表取中图、点开取原图" | "点开识别"失效 | 一条 `· 点开` 都不出现，但改写仍然正常 |

前两条失效是**全局失效**，第三条只影响"有选择的保存"这个附加功能。所以：

- **同版本的电脑版**（我这边验证的是 8.7.0）：直接可用。
- **别人的机器上如果抖音版本更新了**：改写大概率仍然可用，但"点开识别"需要重新验证一次——用 `追踪模式.bat` 跑一遍，看日志里 `[api-images]` 记的三档模板名和 `[trace]` 里实际请求的模板是否还对得上。
- **Windows 专用**：改的是系统代理（WinINET / 注册表）。macOS 和 Linux 用不了，代理内核本身是跨平台的，但设置代理那一段得重写。
- **顺带一个好处**：同一个系统代理下，Chrome / Edge 访问 `www.douyin.com` 也走这套改写，所以浏览器里存的评论图同样是无水印的。

## 我验证到什么程度

已经在本机跑通了完整的端到端自测（`work/proxy-test.mjs`，12 组用例 / 51 项断言全过，用假上游替代抖音，不需要外网）：

- 经 CONNECT 建立隧道、用本工具签发的证书完成 TLS 握手并通过链校验
- 客户端同时提供 h2 时，能正确回落到 HTTP/1.1 以便解析
- 评论接口响应里 `owner_watermark_image` / `download_url` / `thumbnail_url` 全部被改写成 `origin_url`
- 非评论接口原样放行；非抖音域名走原始隧道不做中间人
- gzip 响应被正确解压后改写、去掉 `content-encoding` 和 `ETag`
- 看门狗在没有待还原备份时不会误改任何设置
- 装证书失败时如实报错、退出码非 0，不会谎报"已安装"

**没验证的部分**：我这边访问不了抖音，所以"抖音电脑版是否真的走系统代理"、"客户端是否真的用
`owner_watermark_image` 这个字段来保存"这两点，得由你跑一次才知道。
如果一条 `· 点开` 都没有，说明这个客户端版本的请求特征变了，用 `追踪模式.bat` 跑一遍看日志即可定位。
