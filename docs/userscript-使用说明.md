# 抖音评论区 · 无水印原图下载

## 一句话原理

保存评论图片之所以带水印，不是水印"印"在图上，而是保存那一刻客户端换了一张服务器预先合成好的水印图。
评论接口返回的每条图片对象里其实同时有两份地址：

| 字段 | 内容 |
| --- | --- |
| `origin_url` | 原始图，平台没有加水印 |
| `owner_watermark_image` | 预渲染的带水印版本，点"保存"时下载的就是它 |

脚本不去修图，而是把 `origin_url` 那个地址取出来直接下载，所以画质是原始画质，没有二次压缩。

## 安装（两种方式，任选）

### 方式 A：Tampermonkey 用户脚本（推荐，一次装好长期可用）

1. 给 Chrome / Edge 装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点 Tampermonkey 图标 → 管理面板 → `+`（新建脚本）。
3. 把 `douyin-comment-origin.user.js` 的全部内容粘进去，Ctrl+S 保存。
4. 打开 `https://www.douyin.com` 并登录。

### 方式 B：零安装，直接粘控制台

1. 打开 `https://www.douyin.com` 的任意视频页并登录。
2. 按 F12 → Console，把 `douyin-comment-origin.user.js` 全文粘进去回车。

方式 B 也能用，但下载时走浏览器自身的网络请求，偶尔会被 CDN 的跨域策略拦下；
真被拦下时脚本会自动改成"新标签页打开原图"，你右键另存即可。方式 A 没这个问题。

## 使用

1. 打开目标视频，**把评论区展开**。
2. 往下滚评论区（点开一张评论图片效果更好，会促使接口把大图地址吐出来）。
3. 右下角出现"评论原图 N"按钮，数字就是已抓到的原图数量。
4. 点开面板：
   - **下载** —— 存单张
   - **下载全部** —— 批量存
   - **链接** / **复制链接** —— 拿到直链，方便丢给下载器
   - **保存为 JPG** —— 勾上后会把 webp 转成 JPG（默认关，保存原始字节画质最好）

文件默认落到浏览器的下载目录，命名为 `抖音原图_作者_序号.webp/jpg`。

## 已知限制

- 如果图片是上传者自己发的时候就已经带了文字或水印，`origin_url` 里也会有，这种无法去除。
- 评论区图片属于他人作品，二次发布请注意标注来源。
- 接口偶尔会调整字段名。真抓不到时把脚本里 `const DEBUG = false;` 改成 `true`，
  控制台会打印原始响应结构，照着改 `harvest()` 里的取值即可。

## 关于抖音电脑版

我在你这台机器上查过，结论如下：

- 电脑版装在 `C:\Program Files (x86)\ByteDance\douyin`，是 **Electron / Chromium 外壳**
  （目录里有 `LICENSE.electron.txt`、`resources.pak`、`icudtl.dat`），内核是 Blink 136。
- 它调用的接口是 `https://www-hj.douyin.com/aweme/v1/web/comment/list/`，
  **和网页版是同一套 Web API**，只是域名不同。
- 但它**不走浏览器扩展**，所以上面那个用户脚本没法直接装进电脑版。
- 我把磁盘缓存全扫了一遍（`TTNetCache`、`Cache`、`Partitions`，共 968 个文件、雕出 111 张图）：
  里面只有视频封面、头像、静态资源，**评论接口的响应体不进磁盘缓存**，所以"翻缓存"这条路走不通。

于是电脑版需要另一条路：给它挂上 Chromium 调试协议（CDP），从内部读接口响应。
工具在 `../douyin-pc-origin/`：

```bat
1-run.bat
```

它会：彻底退出抖音 → 带 `--remote-debugging-port=9222` 重新启动 → 连上去读评论接口 → 自动翻页 → 直接下载原图字节。

**这条路我还没能替你验证**：抖音当时正在运行，而它是单实例的，我带的启动参数被已存在的实例吞掉了，
端口没能起来。我没有去关你正在用的窗口，所以停在了这一步。
要验证的话，你手动彻底退出抖音（含托盘图标）后再运行 `1-run.bat` 即可 —— 成功的话它会直接开始导出。

如果端口起不来（说明这个版本屏蔽了调试开关），备用方案是代理抓包（mitmproxy / Fiddler）：
在评论接口响应里找 `origin_url`，之后同样用脚本批量下载。需要的话我可以把这个也做成工具。
